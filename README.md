# Experiment - Iris Dataset Analysis

## Aim
To perform exploratory data analysis on the Iris dataset using Python, Pandas, Seaborn and Matplotlib.

## Technologies Used
- Python
- Pandas
- Seaborn
- Matplotlib
- Google Colab
- Iris Dataset

## Dataset
Iris Dataset

The dataset contains 150 flower samples with 5 columns:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

The dataset contains three flower species:
- Setosa
- Versicolor
- Virginica

## Procedure
1. Import the required Python libraries.
2. Load the Iris dataset using Seaborn.
3. Convert the dataset into a Pandas DataFrame.
4. Display the dataset.
5. Explore the dataset features and structure.
6. Analyze the flower measurements.
7. Visualize the dataset using graphs and plots.

## Result
The Iris dataset was successfully loaded and converted into a Pandas DataFrame using Python.

The dataset contains 150 flower samples and 5 columns.

The dataset includes three different species: Setosa, Versicolor and Virginica.
